# GB/T 7713.1-2025《信息与文献 编写规则 第1部分：学位论文》

- 发布日期：2025-08-01
- 实施日期：2026-02-01
- 代替：GB/T 7713.1-2006《学位论文编写规则》
- 归口：全国信息与文献标准化技术委员会（SAC/TC 4）
- 采标：非等效采用 ISO 7144:1986
- 适用：印刷型、缩微型、电子版等所有传播形式的学位论文

> 以下为条款要点摘编，不是标准全文。引用条款号时可直接使用；引用原文时应查标准正式文本。

## 1. 范围（第1章）

本文件规定学位论文的组成部分以及撰写和编排的基本要求与格式；适用于一切反映自然科学和人文社会科学等知识体系的学位论文。

不同学科领域、不同学位类型可依据本文件制定本学科/本学位类型的具体编写规范；申请学位的实践成果另行制定编写规范（引言）。

## 2. 总体要求（第4章）

| 条款 | 要求 |
|---|---|
| 4.1 | 内容应完整、准确。 |
| 4.2 | 应以中文为主要撰写语言，采用《通用规范汉字表》规范汉字；标点符号应符合 GB/T 15834。教学语言为外语的，可用外语撰写，但应有中文题名和中文摘要。 |
| 4.3 | 术语、符号、代号全文统一并符合规范化要求；科技名词符合 CY/T 119；专业术语、缩略词首次出现时注释；外文术语/缩略词首次出现时在译文后用圆括号注明原词全称。 |
| 4.4 | 数字用法符合 GB/T 15835；标识日期和时间的数字符合 GB/T 7408.1。 |
| 4.5 | 计量单位采用国家法定计量单位；量和单位的名称、符号、书写规则符合 GB 3100、GB/T 3101、GB/T 3102。 |
| 4.6 | 印刷型宜用 A4（210 mm×297 mm）；电子版应采用通用文件格式，可提供音频、视频、数据集等数字资料。 |

## 3. 组成部分（第5章）

### 3.1 六个部分（5.1）

a) 前置部分；
b) 正文部分；
c) 参考文献；
d) 附录；
e) 索引；
f) 结尾部分。

具体构成要素见附录 A 表 A.1。

### 3.2 前置部分（5.2）

#### 封面（5.2.1）
- 学位论文**可**有封面。
- 封面应包括题名页的主要信息，如论文题名、论文作者等；其他信息由学位授予单位自行规定。

#### 封二（5.2.2）
- **可**有封二，包括版权声明及作者、导师签名等。

#### 题名页（5.2.3）
学位论文**应**有题名页，主要包括：

| 项目 | 要求 |
|---|---|
| 中图分类号 | 采用《中国图书馆分类法》最新版本标注。示例：G250.7 |
| 学校代码 | 按国务院教育行政部门批准的学校代码标注。 |
| UDC 分类号 | 采用《国际十进分类法》最新版本标注。示例：003.08 |
| 密级 | 按 GB/T 7156 标注；涉密论文应在题名页做出国家秘密标志；非书面形式涉密载体应以明显可识别方式标注；电子文档含国家秘密内容的，标志与正文不可分离。 |
| 学位授予单位 | 授予学位的机构，名称用规范全称。 |
| 题名 | 简明、准确反映最重要特定内容，一般不宜超过 **25 字**，应中英文对照；通常由名词性短语构成，宜避免不常用缩略词、首字母缩写、字符、代号和公式；层次多时可用正题名+副题名；全文各处题名应一致。 |
| 责任者 | 学生姓名、学号、指导教师姓名、专业技术职务等；校外导师应一并列出；由论文指导委员会指导的应列出全部指导教师；姓名附汉语拼音时符合 GB/T 16159。 |
| 申请学位 | 学位类型和类别；学士按学科门类，参照《普通高等学校本科专业目录》；硕士、博士包括学术学位、专业学位，参照《研究生教育学科专业目录》。 |
| 学科专业 | 本科参照《普通高等学校本科专业目录》；硕士、博士参照《研究生教育学科专业目录》。 |
| 研究方向 | 本学科专业范畴下的细分研究领域。 |
| 论文提交日期 | 论文上交到学位授予单位的日期。 |
| 培养单位 | 培养学位申请人的机构，包括院系和研究所等；名称用规范全称。 |

#### 英文题名页（5.2.4）
- **可**有；内容包括英文题名、责任者、申请学位、学科专业和研究方向等；必要时可单独成页。

#### 勘误页（5.2.5）
- 如有，应在题名页后另起页；顶部放置题名、副题名（如有）、作者名。

#### 原创性声明（5.2.6）
- 学位论文**应**有论文原创性声明。
- 声明应体现：恪守学术道德和学术规范，在指导教师指导下独立完成；杜绝抄袭、篡改、伪造等学术不端行为及代买、买卖论文等造假行为；所有引用或参考内容均应标明出处。

#### 使用授权说明（5.2.7）
- 学位论文**应**有使用授权说明。
- 内容应体现：遵守学位授予单位有关保存、使用学位论文的规定；学位授予单位有权保存印刷本和电子版，提供文献检索与阅览服务，并向国家有关部门或机构送交复印件和电子版。

#### 致谢（5.2.8）
- 对论文编写或相关工作给予帮助的组织和个人**宜**致谢。
- 可包括：国家科学基金、奖学金基金、合同单位、资助企业/组织/个人；协助研究或提供便利条件者；提出建议和帮助者；给予转载/引用权的资料、图片、文献、研究思想所有者；其他应感谢者。
- 可单独成页置于摘要页前，也可放在序言、前言或后记中。

#### 摘要页（5.2.9）
- 学位论文**应**有摘要。
- 摘要应具有独立性和自含性；内容应包含与论文等同量的主要信息；宜说明研究目的、方法、结果和结论，**重点是结果和结论**；撰写应符合 GB/T 6447。
- 中文摘要一般 **300～1000 字**，特殊需要可略多。
- 摘要中宜尽量避免图、表、化学结构式、非公知公用符号和术语。
- 每篇论文选 **3～8 个关键词**，用显著字符另起一行排在摘要下方；关键词应体现论文特色，选用专业术语及词汇，在论文中有明确出处；撰写符合 CY/T 173。
- 宜有英文摘要，另起一页置于中文摘要页后；英文摘要内容宜与中文摘要对应，下方标注英文关键词。
- 以外文撰写的学位论文，应以同种语言撰写外文摘要；除外文摘要外，应有中文摘要，置于外文摘要页后并标注中文关键词；为完整描述主要内容，中文摘要宜不少于 **5000 字**。

#### 序言或前言（5.2.10）
- 一般是作者对本篇论文基本特征的简介：研究缘起、背景、主旨、目的、意义、编写体例，以及基金资助、支持、协作经过等；也可在正文引言（绪论）中说明。

#### 目次页（5.2.11）
- **应**有，排在序言和前言之后，另起页。

#### 插图和附表清单（5.2.12）
- 图表较多时**应**分别列出“插图清单”和“附表清单”，置于目次页之后。
- 插图清单列出图序、图题和页码；附表清单列出表序、表题和页码。

#### 注释表（5.2.13）
- 符号、标志、缩略词、首字母缩写、计量单位、术语等的注释说明，如需汇集，可集中置于图表清单之后。

### 3.3 正文部分（5.3）

#### 一般要求（5.3.1）
- 正文部分应**从另页右页开始**，每一章应另起页。
- 通常包括引言（绪论）、主体和结论。
- 引言应包括：所研究领域的历史回顾和前人工作的综合述评，以及研究目的、流程和方法等。
- 正文因学科、选题、方法、结果表达差异很大，不作统一规定；但应实事求是、客观真切、准备完备、合乎逻辑、层次分明、简练可读；应严格遵循学术规范，尊重和借鉴已有成果，注重调查研究，精心设计研究方案，论证缜密、表达准确。

#### 图（5.3.2）
- 包括曲线图、构造图、示意图、框图、流程图、记录图、地图、照片等。
- 图应具有“自明性”，且随文出现；编排符合 CY/T 171。
- 图应有编号：由“图”+从 1 开始的阿拉伯数字组成；图较多时可分章编号。
- 图宜有图题，置于编号之后；编号和图题置于**图下方**。
- 照片主题和主要显示部分轮廓鲜明；放大/缩小复制品应清晰、反差适中；照片上应有表示目的物尺寸的标度。

#### 表（5.3.3）
- 表应具有“自明性”，且随文出现；编排符合 CY/T 170。
- 表应有编号：由“表”+从 1 开始的阿拉伯数字组成；表较多时可分章编号。
- 表宜有表题，置于编号之后；编号和表题置于**表上方**。
- 表一般内容和测试项目由左至右横读，数据依序竖读；宜采用国际通行的**三线表**。
- 表需转页接排时，后续各页应重复表编号，编号后跟表题（可省略）和“（续）”，置于表上方；续表均应重复表头。

#### 公式（5.3.4）
- 公式应另行起，缩格书写，与周围文字留足够空间。
- 两个以上公式应用从 1 开始的阿拉伯数字编号，编号置于括号内，右端对齐；公式较多时可分章编号。
- 较长公式断开转行时，宜在 `=`、`≈`、`<`、`>`、`≠` 等关系符号或 `+`、`−`、`×`、`/` 等运算符号后断开换行；分数线横线长度应略大于分子和分母中较长者。
- 正文中书写分数宜降为一行；可将分数线写为“/”，根号改为负指数。示例：`1/2` 或 `2^(-1/2)`。

#### 引文标注（5.3.5）
- 按 GB/T 7714 执行；可采用顺序编码制或著者-出版年制，但全文统一。
- 顺序编码制示例：`……[235]`；多篇：`[57,83]`、`[255-256]`。
- 著者-出版年制示例：`(Przemienicki, 1968)`；`Brodaway 等（1986）`。

#### 注释（5.3.6）
- 字、词或短语需进一步说明且无具体文献来源时用注释；标注符合 CY/T 121。
- 应控制注释数量；学位论文篇幅长，宜采用文中编号加脚注，置于所注释正文所在页底部。
- 注释编号应与参考文献脚注的圈码相区别。

#### 结论（5.3.7）
- 是最终的、总体的结论，不是正文各段小结的简单重复。
- 应包括核心观点，交代研究局限，提出未来工作意见建议；应准确、完整、明确、精练。
- 不能导出结论时，也可以没有结论而进行必要讨论。

### 3.4 参考文献（5.4）

- 参考文献是文中引用的有具体文字来源的文献集合；著录项目和格式按 GB/T 7714。
- 应置于正文后，**另起页**。
- 所有被引用文献均应列入参考文献。
- 正文中未被引用但被阅读或具有补充信息的文献，可集中列入附录，标题为“参考书目”。
- 著者-出版年制标注时，参考文献表按著者字顺和出版年排序。

### 3.5 附录（5.5）

附录是主体部分的补充，**不是必需**。可作为附录的内容：

- 为整篇材料完整、但编入正文有损条理性和逻辑性的材料（比正文更详尽的信息、研究方法和技术更深入的叙述、对理解正文有用的补充信息等）；
- 篇幅过大或取材于复制品而不便编入正文的材料；
- 不便编入正文的罕见珍贵资料；
- 对一般读者并非必要、但对本专业同行有参考价值的资料；
- 某些重要原始数据、数学推导、结构图、统计表、视频、音频、数据集等。

### 3.6 索引（5.6）

- 可基于论文内容的主题、概念、术语及创新内容编排学位论文索引，置于附录之后。
- 应依据 GB/T 41210 编制。

### 3.7 结尾部分（5.7）

#### 作者简历（5.7.1）
包括教育经历、攻读学位期间发表的学术论文及其他成果等。示例结构：

```
YYYY-MM—YYYY-MM  XX大学计算机系  学士；
YYYY-MM—YYYY-MM  XX大学  攻读博士学位（直博）

获奖情况：
参加项目：
攻读博士学位期间发表的学术论文：
```

#### 其他（5.7.2）
包括后记等。

## 6. 与 2006 版的主要变化（前言）

- 更改“范围”；更改“学位论文”“封面”“题名页”“摘要”“摘要页”“目次”的定义；删除“目次页”“文献类型”“文献载体”定义；新增“学位论文索引”定义。
- 总体要求增加：标点符号依据、科技名词/数字/计量单位规则、电子学位论文格式和内容要求；删除插图及照片的有关内容。
- “学位授予机构”改为“学位授予单位”；“题名和副题名”改为“题名”；密级增加非书面形式论文标识要求；“研究生姓名”改为“学生姓名”，增加列出校外导师要求；申请学位增加专业学位类别；学科专业增加本科教育标注依据。
- 增加原创性声明和使用授权说明；更改摘要页要求，增加英文摘要规定（中文摘要 300～1000 字；外文撰写者附不少于 5000 字中文摘要及中文关键词）。
- 正文增加遵循学术规范要求；增加引用同一作者多篇文献的示例。
- “分类索引、关键词索引”改为“索引”，增加编制依据与要求；更改作者简历及示例；删除学位论文数据集。
- 增加索引编排格式；更改版面和书脊编排格式。
- 区分规范性附录和资料性附录，调整顺序编号；删除学位论文数据集附录。

## 7. 使用提示

- 该标准**没有统一的字体字号表**。学校模板中的“小二号黑体”等要求通常来自学位授予单位规定，不是 GB/T 7713.1-2025 的强制条款。
- 学位论文的“摘要页”与学术论文摘要不同：学位论文摘要可较长（300～1000 字），且必须有独立摘要页。
- 学位论文的参考文献可以列“参考书目”于附录，但正文引用文献必须全部进入参考文献表。
- 电子版学位论文同样适用；电子文档中的密级标志应与正文不可分离（5.2.3 d）。
