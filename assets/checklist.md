## 2. 题名与作者

- [ ] 题名 ≤25 字（学位论文/学术论文）
- [ ] 题名准确、简明，名词性短语
- [ ] 避免不常用缩略词、首字母缩写、字符、代号、公式
- [ ] 中英文题名一致
- [ ] 副题名使用恰当（仅在语义未尽、分篇报道、分阶段结果等情况下）
- [ ] 作者信息完整：姓名、单位、通信方式
- [ ] 作者数量与贡献相符；集体成果列出全部作者
- [ ] 汉语拼音姓名按 GB/T 28039：姓前名后，双名连写，不加短横线，名不缩写
- [ ] 校外导师/全部指导教师已列出（学位论文）
- [ ] 申请学位、学科专业、研究方向按最新目录标注（学位论文）

## 3. 摘要与关键词

- [ ] 摘要具有独立性和自明性
- [ ] 包含目的、方法、结果、结论；重点是结果和结论
- [ ] 字数符合类型：报道性 400 字左右 / 报道-指示性 300 字左右 / 指示性 150 字左右
- [ ] 学位论文中文摘要 300～1000 字；外文撰写者中文摘要 ≥5000 字
- [ ] 客观陈述，无“本文认为”“具有重大意义”等评论/夸张
- [ ] 不重复题名，不复制粘贴原文
- [ ] 不出现图表、公式、参考文献的编号
- [ ] 首次出现的缩写给出全称/中文翻译
- [ ] 关键词 3～8 个
- [ ] 关键词为有检索意义的专业术语，避免“方法”“理论”“分析”等泛词
- [ ] 中英文摘要、关键词内容对应
- [ ] 外文摘要同时翻译题名、作者、单位、关键词

## 4. 正文与章节

- [ ] 章节层级 ≤4 级
- [ ] 章标题 ≤15 字（学术论文）
- [ ] 编号用阿拉伯数字，层级间用下圆点，末位不加点
- [ ] 编号顶格，后空 1 个汉字接标题
- [ ] 标题末尾不加标点
- [ ] 正文另起行，学位论文前空 2 字起排，回行顶格
- [ ] 每一章另起页（学位论文）
- [ ] 引言包含背景、目的、前人工作述评、方法/流程
- [ ] 结论不是各章小结的简单重复，包含核心观点、局限、展望
- [ ] 术语、符号、代号全文统一
- [ ] 专业术语/缩略词首次出现有注释

## 5. 图表与公式

- [ ] 图、表、公式全文统一连续编号
- [ ] 只有 1 幅图/1 个表时也编“图 1”“表 1”
- [ ] 图题在图下方
- [ ] 表题在表上方
- [ ] 表采用三线表
- [ ] 表头无斜线
- [ ] 表头栏目正确、齐全
- [ ] 表身“空白”“—”“0”含义正确
- [ ] 表格转页时重复表编号、表题和表头
- [ ] 图有自明性，图中文字清晰
- [ ] 坐标图标目、单位、量符号规范
- [ ] 照片有尺寸标度
- [ ] 公式另行起、缩格书写
- [ ] 公式编号右端对齐
- [ ] 长公式在关系符号/运算符号后断开
- [ ] 图表先见文字后见图表

## 6. 量与单位、数字、标点

- [ ] 使用法定计量单位
- [ ] 量和单位符号符合 GB 3100、GB/T 3101、GB/T 3102
- [ ] 单位符号正体；数值与单位间留适当空隙（如 `20 ℃`）
- [ ] 量符号斜体（pH 除外）
- [ ] 不使用已废弃量名称（电流强度→电流；定压质量热容→质量定压热容；体积百分浓度→体积分数）
- [ ] 不使用“单位+数”量名称（克数→质量；天数→时间；摩尔数→物质的量）
- [ ] 数字用法符合 GB/T 15835
- [ ] 年份不简写
- [ ] 纯小数有前导 0
- [ ] 数值范围用“～”或“—”，百分数范围两个 `%` 都保留
- [ ] 多位数分节一致（千分撇或千分空）
- [ ] 标点符合 GB/T 15834
- [ ] 并列词语用顿号，并列分句用逗号/分号
- [ ] 书名号、引号嵌套正确
- [ ] 破折号“——”、省略号“……”形式正确
- [ ] 省略号不与“等”同时使用
- [ ] 数值范围与年份范围使用正确的连接号

## 7. 参考文献

- [ ] 正文标注与文后条目一一对应
- [ ] 所有被引文献均列入参考文献
- [ ] 未引用但阅读过的文献放入附录“参考书目”（学位论文）
- [ ] 全文统一使用顺序编码制或著者-出版年制
- [ ] 顺序编码制按引用先后编号
- [ ] 同一处多篇文献 `[1,3]`，连续序号 `[1-3]`
- [ ] 多次引用同一文献在序号外标页码，如 `[2]260`
- [ ] 著者-出版年制格式正确：`(Crane, 1972)`、`(张三等, 2020)`、`(邱均平, 2000a)`
- [ ] 责任者 ≤3 全列；>3 前 3 + “，等”/“，et al.”
- [ ] 西文责任者姓全著录、首字母大写；名缩写不加点
- [ ] 汉语拼音姓名 `Li Jiangning`，不用 `LI J N`
- [ ] 文献类型标识正确（M/J/N/C/D/R/S/P/EB/A/CM/DS/PP 等）
- [ ] 电子资源有载体标识（如 `[J/OL]`）
- [ ] 出版地、出版者、出版年、页码齐全
- [ ] 期刊格式 `年, 卷(期): 页码`
- [ ] 报纸格式 `日期(版次)`
- [ ] 学位论文格式 `地点: 单位, 年: 页码`
- [ ] 标准格式 `标准编号 标准名称[S]`
- [ ] 专利格式 `专利号[P]. 公告日期: 页码`
- [ ] 网络资源有更新日期（有则）和引用日期、URL
- [ ] 非网络文献没有引用日期
- [ ] 中文文献没有补英文版式（2025 版）
- [ ] 永久标识符（DOI/URN 等）著录正确
- [ ] 标点使用标准前置符

## 8. 版面与页码

- [ ] 印刷型学位论文 A4（210 mm×297 mm）
- [ ] 上、左留边 ≥25 mm
- [ ] 下、右留边 ≥20 mm
- [ ] 前置部分罗马数字页码（封面除外）
- [ ] 正文和后置部分阿拉伯数字连续页码
- [ ] 目录页码与正文一致
- [ ] 书脊信息正确（如装订要求）
- [ ] 字体、字号、行距符合学校/期刊模板

## 9. 学术规范

- [ ] 原创性声明已签署（学位论文）
- [ ] 使用授权说明已签署（学位论文）
- [ ] 所有引用均标明出处
- [ ] 无抄袭、篡改、伪造、代写/买卖论文
- [ ] 基金名称、项目编号准确
- [ ] 利益冲突、作者贡献、数据可用性等声明按模板要求提供
- [ ] AI 生成内容、辅助工具使用按学校/期刊要求声明
